        這頁怎麼運作

        資料全部來自你電腦上的同步程式：課程和作業是 moodle_sync.py 寫的 latest.json，信箱是 mail_sync.py 用 IMAP 讀 gms 信箱寫的 mail.json。這頁只放未讀信的寄件者、主旨、開頭一小段，以及「需注意」信件的摘要，完整內文留在你電腦裡。

        每天 Claude 的排程會把兩份檔案讀進來更新這頁；電腦沒開那天就不會更新，右上角的時間戳會告訴你資料是幾號的。同步程式有沒有在跑，可以在 _moodle 資料夾執行 check_task.ps1 看。

        分頁可以用鍵盤 1–4 切換；信箱的排序和篩選會記在這台瀏覽器。點作業或信件會開詳情浮層，要去原網頁用浮層裡的「出處」按鈕；作業浮層可以用 ← → 切換。
